# Unemployment Analysis with Python

## Project Overview
This project focuses on analyzing unemployment trends in India using Python. The main aim is to understand unemployment rates across different states and areas, study the impact of COVID-19, and identify important patterns in the data.

## Datasets
Two unemployment datasets were used for this project:
- Unemployment in India.csv
- Unemployment_Rate_upto_11_2020.csv

## Technologies and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Steps
1. Loaded both unemployment datasets.
2. Checked and cleaned the data.
3. Handled empty rows and checked for missing values and duplicates.
4. Converted date columns into datetime format.
5. Performed Exploratory Data Analysis (EDA).
6. Analyzed state-wise unemployment rates.
7. Compared rural and urban unemployment rates.
8. Studied the impact of COVID-19 on unemployment.
9. Created visualizations to understand monthly unemployment trends.
10. Identified important patterns and policy-related insights.

## Key Findings
- Haryana and Tripura recorded relatively higher average unemployment rates.
- Meghalaya recorded comparatively lower average unemployment rates.
- Urban unemployment was higher than rural unemployment in Dataset 1.
- Unemployment rates increased sharply during April and May 2020.
- Unemployment rates declined after May 2020 in Dataset 2.

## Conclusion
This project helped me understand unemployment trends in India through data analysis and visualization. It also provided insights into the impact of COVID-19 on employment and differences in unemployment rates across states and areas.
